# Protatodex 🥔⚡

**Protatodex** is a compact, high-performance web application designed for **Brotato** players looking to clear remaining unlocked/unbeaten characters using top-tier, low-effort, or "immortal/stand-still" builds.

---

## 🌟 Features

* **Complete Unbeaten Roster Index:** Top 5 optimized build setups for every remaining locked/unbeaten character (including DLC characters).
* **Tag & Theme Filtering:** Sort builds instantly by playstyle themes:
 * 🛡️ *Immortal / Standstill*
 * 🩸 *Life Steal Engine*
 * 💥 *Explosive / AoE*
 * 💰 *Economy / Harvest*
 * 🤖 *Structures / AFK*
 * 🎯 *Ranged Cleaver*
* **Unlocks & Bans Included:** Direct references for item unlock requirements and recommended item/stat bans per build.
* **Mobile & Pixel Optimized:** Responsive viewport designed for high-aspect-ratio displays (e.g., Pixel 10 Pro XL) with fluid scaling and full zoom compatibility.
* **Single-File Architecture:** Zero dependencies, build steps, or external libraries—just open `index.html`.
